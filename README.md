# George Washington High School Way to Graduate

This is a side-scrolling runner game about stay away from distractions in school, try to pass the test and move up to higher grade. Currently almost every US student has their personal smart phone and easy to access to internet, and social media. That lead to the rate of using phone in US class is increasing. As a predictable result, if that rate keep increases the rate of students pass their class will decrease. This project is made to raise awareness of classroom phone distractions

## Requirements
+ Python 3
+ Pygame ce

## Installation
1. Download the GWHS_graduate_game
2. Run the main.py file with IDE like VSCode
