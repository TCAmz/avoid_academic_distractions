# George Washington High School Way to Graduate

- This is school project a runner scroller game about stay away from distractions in school and try to pass the test and move up to higher grade

-  This project is made to raise awareness of classroom phone distractions. Currently almost every US student has their personal smart phone and easy to access to internet, or social media. That lead to the rate of using phone in US class is increasing. As a predictable result, if that rate keep increases the rate of students pass their class will decrease.
